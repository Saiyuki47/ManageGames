ManageGames

A self-hosted web app to keep your video-game collection organized — games, consoles, makers and a wishlist, each behind your own account.

★ View on GitHub Run it locally

What it does

A small, focused collection manager — no clutter, just your library.

🎮

Your game library

Add, edit and remove games, track how many copies you own, and search your collection.

🕹️

Consoles & makers

Group games by console and link each console to the company that makes it.

⭐

Wishlist

Flag the games you still want and keep them on a separate wishlist.

🔒

Personal accounts

Log in and see only your own collection — data is scoped per user, server-side.

Built with

A modern .NET stack with a clean, migration-driven data layer.

ASP.NET Core MVC .NET 10 Entity Framework Core SQLite Cookie authentication EF Core Migrations

Run it locally

It's a server app with its own database, so it runs on your machine — not on this page.

# clone and start
git clone https://github.com/Saiyuki47/ManageGames.git
cd ManageGames
dotnet run --project ManageGames

# then open https://localhost:7200
# a default admin is seeded on first run: user / password1 (change it)

Requires the .NET 10 SDK. The database is created automatically on first start.
