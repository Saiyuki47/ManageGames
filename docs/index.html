ASP.NET Core · .NET 10

ManageGames

A self-hosted web app to keep your video-game collection organized — games, consoles, makers and a wishlist, each behind your own account.

★ View on GitHub Requirements Run it locally

What it does

A small, focused collection manager — no clutter, just your library.

🎮

Your game library

Add, edit and remove games, track how many copies you own, and search your collection — ignoring case and spaces.

⭐

Wishlist

Flag the games you still want and keep them on a separate wishlist.

🕹️

Ready-made console catalog

Starts with 63 consoles of 23 makers, from the Magnavox Odyssey to the Nintendo Switch 2, each linked to its maker. Admins can extend and change it.

👥

Several users

One installation for family or friends: everybody logs in and sees only their own collection. Admins manage the accounts and the shared catalog.

🔒

Secure by default

Strongly hashed passwords with NIST rules, account lockout, sessions you can end per device, and strict security headers.

🚀

Ready to host

Runs on PostgreSQL behind a reverse proxy, with a health endpoint and sessions shared between several instances.

Built with

A modern .NET stack with a migration-driven data layer, tested against a real database.

ASP.NET Core MVC .NET 10 Entity Framework Core PostgreSQL 18 ASP.NET Core Identity Docker Compose Bootstrap 5.3 xUnit v3 + Testcontainers

Requirements

Runs on Windows, macOS and Linux.

💻

To try it on your machine

  • .NET 10 SDK to build and run the app
  • Docker (Docker Desktop, or Docker Engine with Compose) for the database and the tests
  • Git to get the code
  • Free ports 5433 (database) and 7200 (app)
  • A current browser: Chrome, Edge, Firefox or Safari
🌐

To host it for others

  • ASP.NET Core 10 Runtime on the server (the SDK isn't needed there)
  • PostgreSQL (tested with version 18), on your own server or as a managed service; the app creates its tables itself
  • HTTPS: a domain with a certificate and a reverse proxy such as Caddy or nginx
  • Regular backups of the database

Run it locally

It's a server app with its own database, so it runs on your machine — not on this page.

# clone, start the database, start the app
git clone https://github.com/Saiyuki47/ManageGames.git
cd ManageGames
docker compose up -d            # local PostgreSQL 18
dotnet run --project ManageGames

# then open https://localhost:7200
# the first start creates the tables, fills in the console catalog and
# creates the account "admin"; its one-time password is printed to the
# console, and you choose your own password at the first login

Forgot your password? dotnet run --project ManageGames -- reset-password <username>
